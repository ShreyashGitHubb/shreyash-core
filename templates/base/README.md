# HackForge Project

Starter generated by HackForge. See `hackforge.config.json` for the selected stack and IDE context.

## Routes

- `/` is the public landing page.
- `/sign-in` contains the email/password sign-in form and optional Google sign-in.
- `/sign-up` contains the email/password account creation form and optional Google sign-in.
- `/dashboard` is the signed-in workspace shell using the selected sidebar or top navigation layout.

Email authentication is wired to the selected Supabase or Firebase project. Set the values in `.env.local` before using auth. The dashboard is a starter UI; add route protection and load real user/project data before production.

## Run locally

```sh
npm install
npm run dev
```

Create a `.env.local` file from `.env.example` before connecting the backend.
